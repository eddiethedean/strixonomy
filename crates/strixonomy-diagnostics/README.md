# strixonomy-diagnostics

> Part of **Strixonomy** (semantic workspace engine).

Ontology lint rules and diagnostic collection for [Strixonomy](https://github.com/eddiethedean/strixonomy).

## Install

```toml
strixonomy-diagnostics = "0.27"
```
