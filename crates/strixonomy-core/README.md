# strixonomy-core

> Part of **Strixonomy** (semantic workspace engine).

Core types, workspace scanner, path sandboxing, and resource limits for [Strixonomy](https://github.com/eddiethedean/strixonomy) (`strixonomy-core`).

## Install

```toml
strixonomy-core = "0.28"
```
