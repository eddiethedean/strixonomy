# Migration: v0.27 → v0.28 (remove OntoCore / OntoCode compat)

v0.28 removes the v0.27 compatibility window for **OntoCore** and **OntoCode** names. Upgrade from v0.27 before moving to v0.28 if you still rely on any legacy surface below.

See [Migration v0.26 → v0.27](v0.27.md) for the original rename from OntoCore/OntoCode to Strixonomy.

## Breaking changes

### Rust / crates.io

| Removed in v0.28 | Use instead |
|------------------|-------------|
| `ontocore` compat crate on crates.io | `strixonomy = "0.28"` |
| `OntoCoreError` type alias | `StrixonomyError` |
| `cargo install` / binary name `ontocore` | `strixonomy` |
| LSP binary `ontocore-lsp` | `strixonomy-lsp` |

Direct `ontocore-*` implementation crates were removed in v0.27; v0.28 drops the last published façade shim.

### LSP

- Custom methods must use the **`strixonomy/*`** prefix only.
- **`ontocore/*`** methods are no longer accepted.

### Workspace paths

The engine and extension no longer dual-read legacy directories. Migrate data before upgrading:

| Legacy (no longer read) | Primary |
|-------------------------|---------|
| `.ontocore/cache/` | `.strixonomy/cache/` |
| `.ontocore/plugins/` | `.strixonomy/plugins/` |
| `.ontocore/diagnostics.toml` | `.strixonomy/diagnostics.toml` |
| `.ontocore/plugin-out` | `.strixonomy/plugin-out` |
| `.ontocore/plugin-disabled.json` | `.strixonomy/plugin-disabled.json` |
| `.ontocode/session.json` | `.strixonomy/session.json` |

Copy or move files manually if you have not already opened the workspace with Strixonomy v0.27 (which wrote primary paths on save).

### VS Code extension

- **`ontocode.*` command aliases** removed — update keybindings and automation to `strixonomy.*`.
- **Automatic migration** from `ontocode.*` settings and `.ontocode/session.json` removed — migrate once on v0.27 or copy settings/files manually.

### Environment variables

Legacy names are no longer accepted. Use **Strixonomy** names only:

| Legacy (removed) | Primary |
|------------------|---------|
| `ONTOCORE_LSP_BIN` | `STRIXONOMY_LSP_BIN` |
| `ONTOCORE_PLUGIN_ACTION` | `STRIXONOMY_PLUGIN_ACTION` |
| `ONTOCODE_E2E_EXTENSION_ROOT` | `STRIXONOMY_E2E_EXTENSION_ROOT` |
| `ONTOCODE_CAPTURE_SCREENSHOTS` | `STRIXONOMY_CAPTURE_SCREENSHOTS` |
| `ONTOCODE_TEST_FIXTURES` | `STRIXONOMY_TEST_FIXTURES` |
| `ONTOCODE_SCREENSHOT_DIR` | `STRIXONOMY_SCREENSHOT_DIR` |
| `ONTOCODE_CAPTURE_SCRIPT` | `STRIXONOMY_CAPTURE_SCRIPT` |
| `ONTOCODE_VSCODE_USER_DATA` | `STRIXONOMY_VSCODE_USER_DATA` |
| `ONTOINDEX_UPDATE_GOLDEN` | `STRIXONOMY_UPDATE_GOLDEN` |
| `ONTOINDEX_UPDATE_FIXTURE_SNAPSHOT` | `STRIXONOMY_UPDATE_FIXTURE_SNAPSHOT` |

### Plugin subprocess env

Plugins receive **`STRIXONOMY_PLUGIN_ACTION`** only (`ONTOCORE_PLUGIN_ACTION` is no longer set).

## Not changed

- **Ontologos** reasoner package names
- Stored ontology IRI **`http://ontocode.dev/ns#swrlRule`** (SWRL rule annotations in Turtle)
- Historical docs, changelogs, and migration guides for v0.27 and earlier

## Verification

After upgrade:

- [ ] `strixonomy --version` shows **0.28.x**
- [ ] Workspace uses `.strixonomy/` paths; plugins load from `.strixonomy/plugins/`
- [ ] CI/scripts use `STRIXONOMY_*` env vars and `strixonomy` / `strixonomy-lsp` binaries
- [ ] LSP clients call `strixonomy/*` methods only
- [ ] VS Code keybindings use `strixonomy.*` commands
